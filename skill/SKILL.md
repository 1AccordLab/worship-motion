# 詩歌影片：設定 JSON ＋ 場景程式 ＋ 單檔編輯器

一句話：**簡單調整只給 JSON；要新風格才寫場景程式**。引擎是固定、測好的，AI 不寫引擎、不寫整頁 HTML。

| 使用者要的 | AI 回覆 | 使用者做 |
|---|---|---|
| 改歌詞、段落、BPM、配色、換內建風格 | 一個 ```json 設定 | 編輯器「請 AI 改」→「把 AI 的回覆整則貼回來」→ 套用 |
| 新風格、新動畫、特殊質感 | 一個 ```js 場景程式（＋可選 ```json 設定） | 同一個貼上框（整則貼上）→ 頂端「存成單檔 HTML」 |

回覆規則（任何 AI 都一樣）：資訊不夠時先**問**（見第零節）；給設定時只回程式碼區塊＋一兩句說明＋「下次可以這樣說」；給**完整**內容，不要只給差異；不要外部資源（字型檔、圖片、網址、import、fetch、DOM）。

編輯器：https://1accordlab.github.io/worship-motion/ （正式版，永遠是最新版；開發中的新功能在 /dev/；也可以用存好的單檔 HTML），用 Chrome 或 Edge 打開。

## 零、引導同工（AI 怎麼接）

同工大多不會下提示詞。**AI 主動問、用選擇題問**，問完再做；同時把好的說法教給同工。

### 提問規則

1. **缺什麼問什麼**：第一句已經講清楚的（歌詞、感覺、風格）不要再問；講得夠就直接做。
2. **一次最多 3 題**，每題給 3–5 個帶代號的選項，最後一個永遠是「交給你決定」。同工回「1B 2A 3C」就好。
3. **選項要能想像**：用畫面、用場合描述（「像音樂節海報」「像手作卡片」），不要只丟術語。
4. **同工描述不出來時**，換個問法：「聯想到什麼東西、材質、年代、海報或品牌？」「哪一首歌或哪一場聚會的畫面你很喜歡？」
5. **歌詞由同工自己貼**：AI 給設定時 `lyrics` 可以留空（受版權保護的歌詞不要由 AI 重打），請同工在編輯器「自己調 → 貼上整首歌詞」貼整首，會自動分段；先做背景也可以。
6. **雙語（中英）**：段落設定 `lyrics2`（第二語言）與 `swapLang`（大小對調），中英各一版的段落就做兩段，例如「副歌（中）」「副歌（英）」，後者 `swapLang: true`。

### 新歌：第一輪提問（照缺的挑，最多 3 題）

```
1. 這首歌給人的感覺？
   A 安靜敬拜　B 溫暖感恩　C 活潑歡慶　D 熱血宣告　E 前面安靜、副歌爆發　F 交給你決定
2. 畫面想要哪一種？
   A 瑞士網格：俐落色塊、跟拍子跳格，像設計展海報
   B 剪紙拼貼：溫暖手作、紙片有影子，像手作卡片
   C 大字排版：大字當背景，像口號海報
   D 包浩斯幾何：圓、三角、原色，活潑像兒童繪本
   E 網點印刷：復古印刷、顏色稍微錯位，像獨立樂團海報
   F 墨染：宣紙上墨慢慢暈開、淡去，像呼吸（安靜敬拜）
   G 光柱：深藍綠底，高窗落下幾道光（安靜敬拜）
   H 天空：雲層慢慢飄，高潮雲開、光束落下（敬拜、高舉）
   I 都不像，我描述給你　J 交給你決定
3. 動態字幕？
   A 不用，只要背景（歌詞用簡報軟體打）　B 重點段落要（導歌、高潮）　C 每段都要　D 交給你決定
```

需要時第二輪再問：顏色（A 風格原色　B 教會主色，給色碼或描述　C 節期：聖誕、復活節…）、段落結構。

### 修改：同工說「怪怪的」「不夠好」時

先問哪裡不對（選擇題）：A 速度節奏　B 畫面太滿或太空　C 顏色　D 字幕　E 整體感覺不對。再照下表改：

| 同工說 | 改什麼 |
|---|---|
| 太躁、太急、看了累 | `jumpBeats` 加大（2→4→8）；`background` 降一級 |
| 太慢、不夠嗨 | `jumpBeats` 減小；`background` 升一級（calm→build→peak） |
| 太亂、太花 | 降成 `calm`；場景程式減少元件或質感層 |
| 太空、太單調 | 升一級；或在場景程式加元件 |
| 太暗／太亮 | 調 `palette.bg`（不要純白、純黑） |
| 顏色刺眼、不像我們教會 | 降低飽和，或換成教會主色 |
| 字出來太急／太慢 | `enterSpeed` 0.7／1.3 |
| 字停太短／太久 | `clipSeconds` |
| 放大的字不對 | 移動 `[ ]` |
| 某個東西不想要、太搶眼、想換顏色、想換位置（例如「光芒不要」「圓太大」「太陽往左一點」） | 設定的 `elements`：`visible`、`opacity`、`params`、`colors`、`dx`、`dy`、`scale`、`rotate`；同工也可以自己在「畫面元素」分頁調，或按「調整畫面」後直接在預覽上拖 |
| 整體感覺不對 | 先換內建 `style`；內建都沒有才寫場景程式 |

### 教同工怎麼說

每次給完設定，最後加一行 **「下次可以這樣說：」**，把這次的答案組成一句完整的話，例如：

> 下次可以這樣說：「示意歌名，熱血宣告，網點印刷風格，導歌和副歌要動態字幕，顏色用教會的墨綠。歌詞如下：…」

同工問「我該怎麼說」時，給這兩個範本和詞庫：

| 用途 | 範本 |
|---|---|
| 新歌 | 「歌名＿＿，感覺＿＿，畫面像＿＿，＿＿段要動態字幕，顏色＿＿。歌詞如下：…」 |
| 修改 | 「＿＿段的（背景／字幕）太＿＿，希望＿＿一點，像＿＿那樣。」 |

| 面向 | 可以用的詞 |
|---|---|
| 節奏 | 跳得快／慢、穩、有呼吸感、跟拍子 |
| 密度 | 滿／空、簡單、留白多 |
| 色調 | 暖／冷、亮／暗、鮮豔／柔和、教會主色 |
| 質感 | 紙、印刷、手繪、俐落、復古、現代 |
| 字幕 | 大／小、進場快／慢、華麗／收斂、重點字 |

### 轉成設定

- **段落照歌來**：主歌、導歌、副歌、橋段、間奏、結尾都可以；同名段落可重複（副歌 2）。沒給結構就照歌詞的空行與標題切。
- **BPM 不知道就省略**（120）。節拍對不準沒關係。

| 感覺 | 背景 `background` | 字幕 `subtitle` |
|---|---|---|
| 安靜、敬拜、禱告、主歌 | `calm` | `none` 或 `gentle` |
| 漸強、預備、導歌 | `build` | `flashy`（每行標一個 `[關鍵字]`） |
| 高潮、宣告、副歌、大合唱 | `peak` | `gentle`（字少、好跟唱）；宣告句用 `flashy` |
| 間奏、結尾、只要背景 | 依情緒 | `none` |

| 風格 `style` | 說明（和編輯器顯示的一致） | 適合 |
|---|---|---|
| `swiss` 瑞士網格 | 俐落色塊、跟著節拍跳格，像設計展海報 | 快歌、現代 |
| `paper` 剪紙拼貼 | 溫暖手作、紙片有影子，像手作卡片 | 青年、見證、溫馨 |
| `type` 大字排版 | 大字當背景紋理，像口號海報 | 宣告、口號型歌詞 |
| `bauhaus` 包浩斯幾何 | 圓、三角、原色，活潑像兒童繪本 | 兒童、歡慶 |
| `riso` 網點印刷 | 復古印刷、顏色稍微錯位，像獨立樂團海報 | 年輕、潮、活力 |
| `ink` 墨染 | 暖色宣紙上，墨慢慢暈開、淡去、再暈開，像呼吸 | 敬拜、安靜的歌 |
| `nave` 光柱 | 深藍到墨綠的底，高窗落下幾道平塗光柱，慢慢淡入淡出 | 敬拜、安靜的歌 |
| `sky` 天空 | 切紙雲層慢慢飄，高潮時雲開、平塗光束落下 | 敬拜、宣告、高舉的歌 |
| `oil` 油彩 | 整個畫面由油畫筆觸構成的 3D 夜景，漩渦星空、滿月、麥田與小村，鏡頭緩慢推移 | 默想、感恩、安靜敬拜的歌 |

使用者說的感覺內建沒有（例如「木刻版畫」「拼布」「海面」），才寫新場景（第二節）。內建都有 `calm` `build` `peak` 三種背景與 `flashy` `gentle` 兩種字幕；`ink` `nave` `sky` 的 `flashy` 是克制版（字重、顏色、慢慢淡入）。

## 一、設定 JSON `worship-motion/1`

```json
{
  "format": "worship-motion/1", "title": "示意歌名", "style": "riso", "bpm": 120,
  "palette": { "pink": "#e2536e" }, "params": {},
  "sections": [
    { "name": "主歌", "background": "calm", "jumpBeats": 4, "loopBeats": 32, "subtitle": "none" },
    { "name": "導歌", "background": "build", "subtitle": "flashy", "clipSeconds": 6, "lyrics": "這是第[一]行示意文字\n這是第[二]行示意文字" },
    { "name": "副歌", "background": "peak", "subtitle": "gentle", "lyrics": "這是第一行示意文字\n這是第二行示意文字" }
  ]
}
```

| 欄位 | 值 | 預設 | 說明 |
|---|---|---|---|
| `format` | `"worship-motion/1"` | — | 固定這個值 |
| `title` | 文字（80 字內） | 新的詩歌 | 歌名，分頁上顯示。一定要帶目前的歌名；沒帶或換了名字，編輯器會當成換成另一首歌 |
| `note` | 文字（400 字內） | 空 | 備註，不影響畫面 |
| `style` | 內建 `swiss` `paper` `type` `bauhaus` `riso` `ink` `nave` `sky`，或自訂場景的 `id` | 沿用目前的風格（新歌是 `swiss`） | 自訂場景要先貼上場景程式 |
| `bpm` | 40–220 | 120 | 會微調到循環格數為整數 |
| `palette` | `{ 鍵: "#rrggbb" }` | 場景原色 | 只填想改的；換風格會清空 |
| `params` | `{ 鍵: 數字 }` | 場景預設 | 場景有定義才有 |
| `sections[].name` | 文字（30 字內） | 「段落 N」 | 段落名稱，例如主歌、副歌 |
| `background` | 場景提供的背景名稱 | 第一種 | 內建場景都有 `calm` `build` `peak`（平靜／累積／高潮） |
| `jumpBeats` | 1 2 4 8 | 場景設定 | 色塊換位：每幾拍跳一次位置 |
| `loopBeats` | 32 64 128 | 32 | 背景循環長度 |
| `subtitle` | `none` 或場景提供的字幕名稱 | `none` | 內建：`flashy` 華麗（一行一支，`[ ]` 標關鍵字）、`gentle` 收斂（空一行分一支，最多 3 行） |
| `clipSeconds` | 2–60 | 場景設定 | 每支字幕長度 |
| `enterSpeed` | 0.5–2 | 1 | 字幕進場速度倍率 |
| `lyrics` | 文字，換行 `\n` | "" | 沒字幕時只當備註；可以留空讓同工自己貼 |
| `lyrics2` | 文字，換行 `\n` | "" | 第二語言歌詞（小字）：和 `lyrics` 同樣的切法、逐行配對，行數不同也可以 |
| `swapLang` | `true` `false` | `false` | 大小對調：第二語言當大字、第一語言當小字 |
| `elements` | `{ 元素名稱: { visible, opacity, params, colors, dx, dy, scale, rotate, locked } }` | 空（全部照風格原本的樣子） | 畫面元素的調整，整首歌都套用。`visible`：`false` 就不畫；`opacity`：0–1；`params`：`{ 鍵: 數字 }`，那個元素自己的參數；`colors`：`{ 配色鍵: "#rrggbb" }`，只換那個元素用的顏色；`dx` `dy`：往右、往下移動幾像素（畫面是 1920×1080，負數是往左、往上）；`scale`：整個元素放大幾倍（0.1–5，預設 1）；`rotate`：順時針轉幾度。大小與旋轉以元素整個活動範圍的中心為軸，會跳位置的元素連跳的位置一起縮放；只想讓東西原地變大，用它的 `params`。鋪滿畫面的元素不能移動、縮放、旋轉。`locked`：`true` 時同工在預覽上點不到這個元素（怕誤動時用），其他調整照常。只填想改的；換風格會清空 |
| `sections[].elements` | 同上 | 空 | 只套用在這一段，蓋過整首歌的調整（例如只有副歌把光芒調淡） |

內建風格配色鍵：swiss `bg org crm dim`｜paper `bg red yel crm pnk`｜type `bg tone org crm`｜bauhaus `bg red yel blu crm`｜riso `bg pink blue yel teal ink`｜ink `bg ink wash warm seal shade`｜nave `bg green win light gold`｜sky `bg blue warm far mid near hill light`。
內建風格的元素（`elements` 的名稱）：riso `discs 大圓` `bar 橫條` `ring 圓環` `ramp 網點漸層` `marks 套準記號` `swatches 色票條` `stripes 斜條紋` `tri 三角形` `progress 進度條` `rays 光芒` `sun 太陽` `dot 小圓`，字幕 `stamps 印章色塊` `chars 歌詞（華麗）` `subline 第二語言` `wipe 開場掃屏` `plate 紙色底條` `lyrics 歌詞（收斂）`｜type `giant 背景大字` `wash 整面閃色` `panel 側邊色塊` `para 段落剪影` `ibeam 直條` `disc 大圓點` `dot 小圓點` `rules 橫線` `ellipsis 刪節號` `progress 進度條` `corner 角落色塊` `ring 圓環` `block 大色塊`，字幕 `flash 開場快閃` `keyword 關鍵字` `words 其他的字` `underline 底線` `subline 第二語言` `plate 深色底條` `lyrics 歌詞（收斂）` `accent 重點短線`｜其他內建風格 `bg 背景`、`text 字幕`（整塊）。可調的參數：riso 的 `discs.size` `sun.size`、type 的 `giant.size`（都是 0.5–1.5，預設 1）。鋪滿畫面、不能移動的元素：type 的 `wash` `flash`、riso 的 `wipe`，以及其他內建風格的 `bg`。例：`"elements": { "rays": { "opacity": 0.5 }, "sun": { "params": { "size": 1.2 }, "dx": -120, "dy": 40 } }`。
純 JSON：雙引號、無註解、無尾逗號；不確定就省略。編輯器會檢查，錯了列出哪段哪欄、不套用。

## 二、做新風格：場景程式

### 最小完整範例

```js
// 最小場景：暖灰底、一條色帶跟拍子跳位置、右上一顆圓跟拍輕跳
const C = { bg: '#2a2925', main: '#d9643a', soft: '#e6dcc8' };

function calm(f, x) {
  const y = x.step([200, 760, 420, 880], 2);              // 每 2 秒（4 拍）跳一個位置
  f.add(rect(0, y, W, y + 40, C.main));
  f.add(circle(1640, 300, 90 * (1 + .06 * pulse(x.t)), C.soft, .9));
}
function gentle(f, x) {                                    // 字幕：段落選的背景＋深色橫條＋逐行淡入
  x.under(f, calm);                                        // 畫段落選的背景（段落沒指定時用 calm）
  f.add(rect(0, 400, W, 680, C.bg, .92));
  x.lines.forEach((l, i) => f.text(l, 960, 480 + i * 120, { px: 84, col: C.soft, a: seg(x.t, i * .1, .5 + i * .1) }));
}

defineScene({
  id: 'bars', name: '色帶',
  palette: C, labels: { bg: '底色', main: '主色', soft: '亮色' },
  backgrounds: { calm: { label: '平靜', jumpBeats: 4, draw: calm } },
  subtitles: { gentle: { label: '收斂', split: 'block', seconds: 16, draw: gentle } },
});
```

### 把畫面拆成元素（建議）

畫面上每個看得出來的東西（一條色帶、一顆圓、一排光芒）寫成一個**元素**：一個小函式 `draw(f, x, e)`，登記在 `elements`；背景用 `use` 列出要疊哪些元素（先列的在下面）。同工就能在編輯器的「畫面元素」分頁把每個元素單獨隱藏、調透明度、換顏色、調參數，也能直接在預覽上拖動、縮放、旋轉，不用回來找 AI。上面的最小範例改成元素的寫法：

```js
// 元素範例：暖灰底上一條跟拍子跳位置的色帶、一顆跟拍輕跳的圓，各是一個可以單獨調整的元素
const C = { bg: '#2a2925', main: '#d9643a', soft: '#e6dcc8' };

function bar(f, x, e) {                                    // 色帶：粗細是這個元素自己的參數
  const y = x.step([200, 760, 420, 880], 2);
  f.add(rect(0, y, W, y + 40 * e.p.thick, C.main));
}
function dot(f, x, e) {                                    // 圓：半徑由各個背景在 use 裡指定
  f.add(circle(1640, 300, e.args.r * (1 + .06 * pulse(x.t)), C.soft, .9));
}
function plate(f) {                                        // 字幕的底條
  f.add(rect(0, 400, W, 680, C.bg, .92));
}
function lyrics(f, x) {                                    // 字幕的歌詞：逐行淡入
  x.lines.forEach((l, i) => f.text(l, 960, 480 + i * 120, { px: 84, col: C.soft, a: seg(x.t, i * .1, .5 + i * .1) }));
}

defineScene({
  id: 'parts', name: '色帶與圓',
  palette: C, labels: { bg: '底色', main: '主色', soft: '亮色' },
  elements: {
    bar: { label: '色帶', colors: ['main'], params: { thick: { value: 1, min: .5, max: 4, label: '粗細' } }, draw: bar },
    dot: { label: '圓', colors: ['soft'], draw: dot },
    plate: { label: '底條', draw: plate },
    lyrics: { label: '歌詞', colors: ['soft'], draw: lyrics },
  },
  backgrounds: {
    calm: { label: '平靜', jumpBeats: 4, use: ['bar', { el: 'dot', r: 90 }] },
    peak: { label: '高潮', jumpBeats: 2, use: ['bar', { el: 'dot', r: 160 }] },
  },
  subtitles: { gentle: { label: '收斂', split: 'block', seconds: 16, use: [{ el: 'under', bg: 'calm' }, 'plate', 'lyrics'] } },   // under＝段落選的背景（沒選時用 calm）
});
```

| `elements.名稱` 的欄位 | 內容 |
|---|---|
| `label` | 中文名稱，顯示在元素清單（例如「光芒」） |
| `draw(f, x, e)` | 只畫這個元素。`e.p`：這個元素的參數值；`e.args`：背景在 `use` 裡給的其他資料；`e.sub`：畫在字幕底下時是 `'line'` 或 `'block'`，可以讓出放大字的位置 |
| `params` | `{ 鍵: { value, min, max, label } }`，這個元素自己的滑桿；讀 `e.p.鍵`。大小、數量、粗細這類同工會想調的值都放這裡 |
| `colors` | 這個元素用到的 palette 鍵，例如 `['main']`；同工可以只換這個元素的顏色。顏色要在 `draw` 裡從 palette 物件讀（`C.main`），不要先存成別的變數 |
| `fixed` | `true`：鋪滿整個畫面的元素（整面底色、整面閃色）。同工只能隱藏、調透明度，不能在預覽上拖它 |

背景的 `use`：元素名稱的陣列，每一項是 `'名稱'` 或 `{ el: '名稱', 其他資料 }`；同一個元素可以用在好幾種背景，各給不同的資料。元素之間不要互相依賴（一個元素被隱藏，其他的要照常畫）。元素名稱的規則和背景名稱一樣，不要用 `bg`、`text`（保留給「整個背景」和「字幕」）。字幕也用 `use` 組合：把歌詞、底條、開場效果各寫成一個元素，同工才能只拖歌詞、不動底條。字幕的 `use` 裡用 `'under'` 或 `{ el: 'under', bg: '背景名稱' }` 代表「段落選的背景」（沒選時用 `bg` 指定的那一種），通常放第一個。字幕元素的 `draw(f, x, e)` 一樣從 `x` 讀歌詞（`x.lines`、`x.chars`、`x.big`、`x.small`…）；幾個元素要用同一套排版時，把算位置的部分寫成一個共用函式。只在開頭閃一下、鋪滿畫面的效果標 `fixed: true`。背景或字幕寫成一個 `draw(f, x)` 也可以，這時它在清單上是一整個元素「背景」或「字幕」，同工只能整塊調。元素名稱不要用 `under`。

### `defineScene({...})`（整份程式只呼叫一次）

| 欄位 | 必填 | 內容 |
|---|---|---|
| `id` `name` | name 必填 | id：英文名稱（寫進 JSON 的 style，規則見下；省略＝`custom`）；name：中文風格名（30 字內） |
| `description` | | 一句話、80 字內，顯示在編輯器的風格說明；新風格建議填 |
| `palette` | ✔ | `{ 鍵: "#RRGGBB" }`，一定要有 `bg`。繪圖時從這個物件讀，編輯器會把使用者改的顏色填進來 |
| `labels` | | 面板可調的顏色 `{ 鍵: "名稱" }`（省略＝全部） |
| `elements` | | `{ 名稱: { label, draw(f, x, e), params, colors } }`：畫面上可以單獨調整的元素，見上「把畫面拆成元素」 |
| `backgrounds` | ✔ | `{ 名稱: { label, jumpBeats, draw(f, x) } }`，或用 `use: [元素…]` 取代 `draw`。可以做通用的 `calm` `build` `peak`，也可以每一段各設計一種背景（例如 `verse1`、`chorus1`、`bridge`）；`label` 寫中文，面板上會顯示 |
| `subtitles` | | `{ 名稱: { label, split: 'line'或'block', seconds, draw(f, x) } }`，或用 `use: ['under', 元素…]` 取代 `draw`。建議 `flashy`（line）`gentle`（block）。可以只做兩三種共用，也可以每一段各做一種（例如 `verse1Text`、`chorus1Text`…，七種也沒問題）；歌詞一律放在 JSON 的 `sections[].lyrics`，不要寫死在場景程式裡，改歌詞才不用改程式 |
| `params` | | `{ 鍵: { value, min, max, label } }` → 面板滑桿；JS 讀 `x.params.鍵`，shader 讀 `param(第幾個)` |
| `look` | | 後製 `{ grain: .035, vignette: .22, paper: .05, lift, cap }`；lift ≥ .015、cap ≤ .95 是固定下限上限 |
| `textures` `canvas` `shader` | | 三層質感出口，見下 |
| `world` | | 3D 筆觸世界 `{ z, build(w, x), camera(t, x) }`，見下「D」 |

**命名規則**：`id`、背景名稱、字幕名稱都用英文字母開頭，只能有英文、數字、`-`、`_`（例：`inkwash`、`peak`、`verse1Text`），不要用 `none`。編輯器比對時不分大小寫、不計 `-` 和 `_`，`id` 會自動轉小寫。

### `draw(f, x)`：每一格呼叫一次

| `x.` | 意思 |
|---|---|
| `t` | 秒。**永遠當 120 BPM 寫**（1 拍＝0.5 秒），編輯器依實際 BPM 伸縮 |
| `beat` | 拍數（`t × 2`） |
| `step(陣列, 每幾秒, t?)` | 依時間輪流取陣列的下一個：位置用「跳」的。會跟面板的「色塊換位」連動 |
| `jt(t)` | 換位用時間（自己算跳位時用） |
| `pal` `params` | 目前配色、參數 |
| `text` `lines` `chars` `kw` `dur` | 字幕：原文、各行（去掉 `[ ]`）、大字那一行的字陣列、`[ ]` 那個字的位置、影片長度 |
| `text2` `lines2` | 第二語言：原文、各行（和 `lines` 逐行配對） |
| `big` `small` | 依 `swapLang` 對調好的兩組行：`big` 畫大字、`small` 畫小字（沒有第二語言時 `small` 是空陣列，畫面要和單語一樣） |
| `swap` | 這段有沒有大小對調 |
| `bg` `under(f, 預設, 選項)` | 字幕用。`x.bg`：段落選的背景名稱（沒選或這個風格沒有就是 `null`）。`x.under(f, calm)`：畫段落選的那種背景當字幕的底；`x.bg` 是 `null` 時畫第二個參數那個背景（背景函式，或背景名稱例如 `'calm'`；省略則用第一種背景）。背景的 `draw(f, x, o)` 會收到 `o.sub`（`'line'`＝華麗、`'block'`＝收斂），可以在字幕底下讓出放大字的位置 |

| `f.` | 用法（z：大的在上） |
|---|---|
| `f.add(形狀…)` | 形狀，z 0（可傳陣列） |
| `f.top(形狀…)` | 蓋在字上面，z 2（開場掃屏用） |
| `f.text(字, x, y, { px, weight, col, a, scale, rot, align, spacing, stroke, blur, shadow, z })` | 字，z 1，(x, y) 是中心；`align:'left'`／`'right'` 時 x 是左／右緣；`shadow:true` 用 blur 過的版本 |
| `f.measure(字, 同上)` | `{ tw }` 字寬，排版用 |
| `f.fit(字, 最大寬, 同上)` | 縮放倍率（≤ 1），讓這行字不超過最大寬；傳給 `scale` |
| `f.line(x0, y0, x1, y1, 粗細, 色, a)`、`f.poly(點陣列, 粗細, 色, a)` | 線，z 0 |
| `f.bg`、`f.grid = { alpha, flash, col, w, h, line }` | 底色（預設 palette.bg）、網格線（`flash` 疊加亮度、`line` 線寬） |

| 形狀 | 參數 |
|---|---|
| `rect(x0, y0, x1, y1, 色, a)` | 矩形 |
| `band(cx, cy, 長, 寬, 角度°, 色, a)` | 旋轉長條 |
| `circle(cx, cy, r, 色, a)`、`wedge(cx, cy, r, 起始弧度, 弧長, 色, a)` | 圓、扇形 |
| `arc(cx, cy, r, 粗細, 起始弧度, 弧長, 色, a)` | 圓弧／圓環（弧長 ≥ 2π＝整圈） |
| `tri(cx, cy, 外接半徑, 旋轉弧度, 色, a)` | 正三角形 |

形狀最後可再加一個物件：`{ z, blend: 'multiply'（疊印）, tex: false（不套質感）, rough（手撕邊 px）, shadow（紙影）, fiber（紙纖維） }`。
內建工具：`W` `H`（1920×1080）`BEAT` `BAR` `LOOP`（16）`TAU`、`lerp` `clamp01` `seg(t,a,b)` `mod` `hash(n)` `pulse(t, k, 週期)` `E.io/out/out5/back`。

**雙語字幕**：`small` 有內容時，每行大字下方一行小字（約 0.42–0.5 倍字級、同色較淡），不擠不疊、在歌詞區內；`flashy` 的放大效果只用在大字行。

**時間規則**：背景在 t＝16（32 拍）頭尾相接——用 `mod(x.t, 16)`、正弦用整數圈數（`TAU * 圈數 * t / 16`）。字幕不循環。中間 x 420–1500、y 260–820 留給簡報軟體疊歌詞。

### 質感出口：由安全到自由

| 想要 | 用哪層 | AI 寫什麼 |
|---|---|---|
| 紙纖維、底片顆粒、網點、套色錯位、墨水暈染、絹印粗糙邊、手繪抖動 | **A 質感庫** | 只寫參數 |
| 筆觸、排線、不規則圖案、Canvas 漸層與路徑 | **B Canvas2D 自由畫層** | `draw(ctx, t, info)` |
| 整個畫面的特殊處理（雙色網點、版畫、色調分離） | **C 自訂 WGSL** | 一個 `fn shade` |
| 有景深、鏡頭會推移的畫面（油畫、粉彩、點描的風景） | **D 3D 筆觸世界** | `build(w, x)` 擺筆觸＋`camera(t, x)` |

**A. `textures`**（最多 8 層，依序套用；`on`：`shapes` `text` `lines` `bg`，可用逗號合併）

```js
textures: [
  { type: 'halftone', on: 'shapes', cell: 9, angle: 22 },       // 半透明的形狀印成網點（a 越小點越小）
  { type: 'misreg', on: 'shapes,text', amount: 4, every: 8 },   // 每種墨色偏一點，每 8 拍重新對位
  { type: 'fiber', on: 'bg', amount: .16 },
],
```

| type | 參數（預設） | 效果 |
|---|---|---|
| `fiber` | amount .12 | 紙纖維 |
| `grain` | amount .04 | 底片顆粒（每格不同） |
| `halftone` | cell 8、angle 15、tone 1 | 濃度＝透明度×tone，變成網點 |
| `misreg` | amount 4、every 0 | 套色錯位（依顏色）；every＝幾拍重新對位 |
| `bleed` | amount 6 | 墨水暈染（形狀、線） |
| `rough` | amount 3、voids .15 | 絹印粗糙邊＋漏墨 |
| `wobble` | amount 3、scale .012、fps 8 | 手繪抖動，每秒換 fps 次 |

**B. `canvas`**：在另一個執行緒畫，畫完疊在 z 的位置。只能用自己的參數（`info.pal`、`info.params`、`info.beat`、`info.text`）和內建小工具（`hash` `lerp` `seg` `mod` `pulse`），**不能用外面的變數**。`half: true` 用半解析度。

```js
canvas: { z: .5, draw(ctx, t, info) {
  const k = Math.floor(t * 8);                                    // 每秒抖 8 次，像手繪
  ctx.strokeStyle = info.pal.soft; ctx.lineWidth = 2;
  for (let i = 0; i < 40; i++) { const x0 = 80 + i * 14 + (hash(i + k) - .5) * 5;
    ctx.beginPath(); ctx.moveTo(x0, 90); ctx.lineTo(x0 - 90, 380); ctx.stroke(); }
} },
```

**C. `shader`**：只寫 `fn shade(uv: vec2f, t: f32, beat: f32, base: vec4f) -> vec4f`，回傳這一點的新顏色。`base`＝底下圖層在這一點的顏色。可用：`scene(uv)` 取樣底下圖層、`pal(i)`（palette 第 i 個顏色）、`param(i)`、`hash(p)`、`noise(p)`、`RES`（1920×1080）。z 預設 .5＝只處理背景，字保持清楚；z 9＝連字一起。

```js
shader: { z: .5, code: `
fn shade(uv: vec2f, t: f32, beat: f32, base: vec4f) -> vec4f {
  let px = uv * RES;
  let l = dot(base.rgb, vec3f(0.299, 0.587, 0.114));
  let q = mat2x2f(0.966, -0.259, 0.259, 0.966) * px / 10.0;           // 網點轉 15°
  let ink = 1.0 - smoothstep(-0.04, 0.04, length(fract(q) - 0.5) - sqrt(clamp(0.85 - l, 0.0, 1.0)) * 0.62);
  return vec4f(mix(pal(0), pal(0) * pal(1), ink), 1.0);               // 紙色上印一版墨（相乘＝疊印）
}` },
```

**D. `world`**：3D 世界直接由一筆一筆筆觸構成（不是先畫好 3D 再套濾鏡）。`build(w, x)` 在換配色或參數時跑一次，擺好所有筆觸；`camera(t, x)` 每一格回傳鏡頭。整層疊在 z 的位置（字幕在 z 1，`z: .2` 就在字的下面）。單位是公尺，y 朝上，鏡頭預設看 −z。

```js
world: { z: .2,
  build(w, x) {
    w.moon([.4, .5, -.7], '#e9dcae', .3);                       // 主光從哪個方向來、光色、環境光
    w.lamp([30, 2, -80], 7, x.pal.lamp);                        // 燈火：半徑 7 公尺內的筆觸偏暖
    for (let x0 = -60; x0 <= 60; x0 += 4) w.stroke([x0, -1, -60], [0, 1, 0], [0, 0, 1], 3, 2.4, '#1c2a3a', null, { brush: 'flat', keep: 1 });
    for (let i = 0; i < 40000; i++) {
      const p = [(hash(i) - .5) * 120, 0, 10 - hash(i + .5) * 70], d = Math.hypot(p[0], p[2] - 14);
      w.stroke(p, [1, 0, (hash(i + .3) - .5) * .6], [0, 1, .4], d * .015, d * .005, x.pal.grass, x.pal.night);   // 位置、筆刷方向、朝向、半長、半寬、亮部色、暗部色
    }
  },
  camera(t, x) { const e = (1 - Math.cos(TAU * t / 16)) / 2; return { eye: [0, 3, 14 - 4 * e], at: [0, 6, -100], fov: 50, fog: '#2a3a66' }; },
},
```

| 小工具 | 用法 |
|---|---|
| `w.stroke(位置, 方向, 朝向, 半長, 半寬, 亮部色, 暗部色, o)` | 一筆。依受光在亮部色、暗部色之間選色，再加一點隨機色差。`o`：`brush: 'oil'`（刷毛加厚塗受光，預設）或 `'flat'`（平塗）；`flow: [移動距離, 每秒幾圈]` 沿方向慢慢流動，頭尾漸漸長出、縮小（每秒圈數用 1/16 才接得起來）；`keep: 1` 剪影墊底（永遠畫、不變稀）；`lit: 0–1` 指定受光；`fog: 0` 不受霧影響；`jitter` 色差（預設 .06，0＝不加）。顏色可以寫 `"#RRGGBB"` 或 `[r, g, b]`（0–1）；暗部色省略或 `null`＝和亮部同色 |
| `w.moon(方向, 光色, 環境光)` `w.lamp(位置, 半徑, 光色, 強度)` | 主光：朝向光的筆觸偏亮部色、帶一點光色，背光的偏暗部色（環境光＝最暗也有幾成亮部）。燈火：半徑內的筆觸偏向燈火色 |
| `v3.add` `sub` `mul` `dot` `cross` `len` `norm` `lerp` | 三維向量小工具（陣列 `[x, y, z]`） |
| `camera` 回傳 | `eye` `at`（必填）、`fov`（45）、`fog` 霧色（省略＝不加霧）、`fogNear` `fogFar`（30、300 公尺）、`minPx` `maxPx`（筆觸在畫面上的半長上下限，1.5、48 像素）、`lod`（6 像素：比這小的筆觸會變稀、變大，再慢慢縮小消失） |

畫得好看的規則：
- **筆觸大小跟離鏡頭的距離成正比**：遠處的筆觸在世界裡比較大，畫面上看起來才差不多大；遠處的筆觸也放少一點。
- **大面積先墊剪影**：山、地面、樹身先用 `keep: 1` 的平塗筆觸鋪一層，筆觸之間的縫隙才不會露出底色。
- **亮部、暗部兩組顏料**：同色系，一亮一暗；夜景的亮部偏藍、飽和度低，只有燈火照到的地方是暖色。
- **鏡頭只推、移、升**，16 秒頭尾接得上（用 `cos`／`sin` 整數圈），不要繞著東西轉。
- **數量**：一個風格最多 40 萬筆，建議 10–25 萬筆。編輯器預覽跟不上時會自動少畫，匯出一律畫滿。

### 編輯器會擋什麼

| 情況 | 結果 |
|---|---|
| 語法錯、執行錯、API 用錯 | 不套用、標出**第幾行**、保留原本的風格（把訊息貼回給 AI 修） |
| 場景程式卡住（無窮迴圈） | 載入超過 3 秒、一格超過 1 秒（第一格 5 秒）、`world` 建筆觸超過 15 秒就停止；執行中才卡→退回內建風格 |
| Canvas 一格畫超過 1 秒 | 停用這一層，其他照常 |
| WGSL 有 `loop` `while` `@` `var<…>` `textureStore`、指標；`for` 不是「常數、≤64 次」；巢狀總次數 >4096；超過 6000 字；改迴圈變數 | 靜態擋下（標行號） |
| WGSL 編譯錯誤 | 擋下（標行號） |
| `world` 沒有 `build`、筆觸超過 40 萬筆、`w.stroke` 參數不對、鏡頭 `eye` 和 `at` 同一點或 `fov` 不在 5–150 | 擋下並說明 |
| 鏡頭的 `minPx` `maxPx` `lod` 太極端 | 自動限制在 0.5–8、4–160、2–40 像素 |
| 預覽跟不上（筆觸太多、電腦太慢） | 預覽自動少畫一些筆觸；匯出一律畫滿 |
| shader 太慢 | 先在極小畫面試跑測速；太慢自動改半解析度；還太慢就拒絕並說明 |
| 顯示卡卡住／斷線 | 自動重建、停用自訂 shader、專案不變 |
| 試跑時整頁當掉 | 下次打開會發現，預設停用那段程式並提示 |
| 在 AI 對話的預覽視窗裡打開（編輯器提示「這個環境（例如 AI 對話裡的預覽）限制比較多」） | 自動改在頁面裡執行：能看、能改，但沒有無窮迴圈保護；匯出與試新場景請下載後用 Chrome／Edge |

### 固定規則（只有兩條）

1. **背景不放字**（大字排版 `type` 的同色系大字紋理例外）。歌詞只在字幕影片。
2. **不要 AI 常見的效果**：光暈粒子、鏡頭光斑、霓虹發光、漸層球、玻璃擬態、無意義的 3D 旋轉。要質感就用印刷、紙、手作：網點、套色錯位、紙紋、粗糙邊、手繪抖動。

其他都是可調預設：位置用跳的、120 BPM 寫法、32 拍循環、配色、字幕長度。不要純白、純黑（後製 lift/cap 會擋）。

### 回覆前自我檢查

- [ ] 該問的先問了；回覆最後有「下次可以這樣說」。
- [ ] JSON 是純 JSON；`format` 是 `worship-motion/1`；每段都有 `background`。
- [ ] `flashy` 每行最多一個 `[ ]`；`gentle` 每支最多 3 行。
- [ ] 背景的 `draw` 沒有 `f.text`（`type` 風格的大字紋理例外）。
- [ ] 新風格的背景和字幕都拆成元素（`elements`＋`use`）：每個看得出來的東西一個元素，有中文 `label`，會想調的值放 `params`；字幕至少把歌詞和底條分開。
- [ ] 字幕的底用 `x.under(f, 某個背景)`（用 `use` 組合時是清單裡的 `under`），不要寫死成某一種背景：段落選平靜，字幕底下就要是平靜。
- [ ] 沒有光暈、光斑、霓虹、漸層球、玻璃、3D 旋轉；沒有純白 `#ffffff`、純黑 `#000000`。
- [ ] 背景在 16 秒頭尾接得上；位置變化用 `x.step` 跳，不是一直滑。
- [ ] 歌詞區（x 420–1500、y 260–820）在背景影片裡保持乾淨。
- [ ] 用 `world` 時：山、地面、樹身先用 `keep: 1` 的平塗筆觸墊剪影；筆觸大小跟離鏡頭的距離成正比；鏡頭 16 秒接得上、只推移升降，不繞圈轉。
- [ ] 給的是完整程式，不是片段；沒有 import、fetch、網址、圖片。
- [ ] 名稱（id、背景、字幕）英文字母開頭、只有英文數字 - _；JSON 的 style／background／subtitle 對得上這些名稱；歌詞在 JSON，不在程式裡。

### 做不到的（直接說明，不要硬做）

## 三、匯出與放進簡報軟體

| 項目 | 做法 |
|---|---|
| 匯出 | 單支 MP4、這一段 ZIP、整首 ZIP、全部歌曲 ZIP（每首一個資料夾）；檔名照段落順序編號 |
| 背景影片 | 放進簡報軟體後設成**循環**；歌詞用簡報軟體自己的文字疊上去 |
| 字幕影片 | 一句一支，播一次、停在最後一格；換句就換下一支 |
| 存檔 | 一個分頁一首歌；「存成單檔 HTML」存整本（打開還是多分頁），分頁「⋯」→「只存這一首」；收在同一個雲端資料夾，下次直接打開接著改 |
| 歌詞 | 「自己調 → 貼上整首歌詞」：認得段落標題、濾掉版權行、中英交錯可選怎麼放、可轉繁體；全在瀏覽器裡處理 |
| 改錯了 | 頂端「↶ 還原」「↷ 重做」（Ctrl／⌘＋Z）；「進階 → 歷史紀錄」可回到最近 50 步的任一個狀態；關掉的分頁從「最近關閉」叫回 |
| 字型 | 用電腦內建字型，**在要播放的那台電腦上匯出**，字形才一致 |
| 規格 | 1920×1080、30fps、H.264 的 MP4；只用 WebGPU、不連網、不用外部函式庫 |
